# Attribution and Source Boundaries

DER26 ECU firmware is a team vehicle software project. This repository combines project-authored application code with vendor-generated/support code.

## Project-authored / team-maintained areas

Primarily:

- `Core/Src/tasks/`
- `Core/Src/power/`
- most project-specific modules in `Core/Src/ext_drivers/`
- matching project interfaces/configuration in `Core/Inc/`
- `host_tests/`
- `ci/`
- `Tools/`
- `docs/`

## Vendor/generated areas

Primarily:

- `Drivers/`
- `Middlewares/`
- portions of `Core/` generated by STM32Cube tools
- `FATFS/` integration/support

Vendor headers and source retain their original notices/licenses. Generated STM32 files retain their generated structure so CubeIDE/CubeMX workflows remain reproducible.

## Documentation

The maintained docs describe the current project behavior and validation strategy. They should not be used to erase authorship history from Git; code-review/commit history remains the detailed record of individual contributions.
